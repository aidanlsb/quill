# Vendored pstack skills

Source: https://github.com/cursor/plugins/tree/a968159326d1fc6b7d483491ec5c457986a20af2/pstack

License: [pstack-LICENSE](pstack-LICENSE) (MIT).

These are the skills this repo asks agents to use. The rest of pstack is not vendored. That includes `typescript-best-practices` and the chat helpers.

Included:

- `create-verification-skill`, `maintain-verification-skill`
- `correct`, `architect`, `blast-radius`, `interrogate`, `tdd`, `show-me-your-work`
- `principle-prove-it-works`, `principle-fix-root-causes`, `principle-sequence-verifiable-units`, `principle-subtract-before-you-add`, `principle-type-system-discipline`, `principle-boundary-discipline`

`verify-quill` is this repo's own skill, generated from `create-verification-skill`. It is not part of the upstream copy.
